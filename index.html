charly-openwrt

The OpenWrt package feed for charly — the OpenCharly CLI and its composed toolchain, packaged as .ipk for amd64 and arm64.

Add the feed

mkdir -p /etc/opkg/keys
wget -O /tmp/charly.pub https://opencharly.github.io/charly-openwrt/charly.pub
cp /tmp/charly.pub /etc/opkg/keys/$(usign -F -p /tmp/charly.pub)
echo "src/gz charly https://opencharly.github.io/charly-openwrt/amd64" >> /etc/opkg/customfeeds.conf
opkg update
opkg install charly

For arm64 hosts, use https://opencharly.github.io/charly-openwrt/arm64 in customfeeds.conf.

charly.pub — the usign public key used to sign the Packages index. Install it into /etc/opkg/keys/ named by its fingerprint (usign -F -p charly.pub).
